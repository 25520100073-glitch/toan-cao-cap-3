Bài B4.8

Đề bài: Tính \(\iiint_\Omega xyz\,dxdydz\), với \(\Omega\) là một phần tám khối cầu \(x^2+y^2+z^2 \le 2,\; x \ge 0,\; y \ge 0,\; z \ge 0\).

✎ Lời giải

Bước 1: Xác định cận trong tọa độ cầu cho góc phần tám thứ nhất

Miền \(\Omega\): \(x^2+y^2+z^2 \le 2\) và \(x \ge 0,\; y \ge 0,\; z \ge 0\).

  • Bán kính mặt cầu là \(R = \sqrt{2} \implies 0 \le \rho \le \sqrt{2}\).
  • Vì \(z \ge 0\) nên góc cực \(\theta\) chỉ đi từ trục \(Oz\) dương đến mặt phẳng \(Oxy\): \(0 \le \theta \le \frac{\pi}{2}\).
  • Vì \(x \ge 0,\; y \ge 0\) (góc phần tư thứ nhất trên \(Oxy\)) nên góc phương vị: \(0 \le \varphi \le \frac{\pi}{2}\).

Bước 2: Biến đổi hàm dưới dấu tích phân

Thay \(x = \rho\sin\theta\cos\varphi,\; y = \rho\sin\theta\sin\varphi,\; z = \rho\cos\theta\) và \(dxdydz = \rho^2\sin\theta\,d\rho\,d\theta\,d\varphi\):

\[ xyz\,dxdydz = (\rho\sin\theta\cos\varphi)(\rho\sin\theta\sin\varphi)(\rho\cos\theta) \cdot \rho^2\sin\theta\,d\rho\,d\theta\,d\varphi \] \[ = \rho^5 \cdot (\sin^3\theta\cos\theta) \cdot (\sin\varphi\cos\varphi)\,d\rho\,d\theta\,d\varphi \]
🔎 Giải thích chi tiết về chiều cao \(z\) trong bài toán:
  • Trong tọa độ cầu, chiều cao \(z\) được thay bằng \(z = \rho\cos\theta\).
  • Điều kiện \(z \ge 0\) (thuộc góc phần tám thứ nhất) tương đương \(\rho\cos\theta \ge 0 \iff \cos\theta \ge 0 \iff \mathbf{0 \le \theta \le \frac{\pi}{2}}\) (chỉ lấy từ trục \(Oz\) dương tại \(\theta=0\) xuống tới mặt sàn \(z=0\) tại \(\theta=\frac{\pi}{2}\)).

Bước 3: Tách tích phân và tính từng biến

\[ I = \left( \int_0^{\pi/2} \sin\varphi\cos\varphi\,d\varphi \right) \cdot \left( \int_0^{\pi/2} \sin^3\theta\cos\theta\,d\theta \right) \cdot \left( \int_0^{\sqrt{2}} \rho^5\,d\rho \right) \]
  • Theo \(\varphi\): Đặt \(u = \sin\varphi \implies du = \cos\varphi\,d\varphi\): \[ \int_0^{\pi/2} \sin\varphi\cos\varphi\,d\varphi = \left[ \frac{\sin^2\varphi}{2} \right]_0^{\pi/2} = \frac{1^2}{2} - 0 = \frac{1}{2} \]
  • Theo \(\theta\): Đặt \(v = \sin\theta \implies dv = \cos\theta\,d\theta\): \[ \int_0^{\pi/2} \sin^3\theta\cos\theta\,d\theta = \left[ \frac{\sin^4\theta}{4} \right]_0^{\pi/2} = \frac{1^4}{4} - 0 = \frac{1}{4} \]
  • Theo \(\rho\): Lưu ý \((\sqrt{2})^6 = (2^{1/2})^6 = 2^3 = 8\): \[ \int_0^{\sqrt{2}} \rho^5\,d\rho = \left[ \frac{\rho^6}{6} \right]_0^{\sqrt{2}} = \frac{8}{6} = \frac{4}{3} \]

Bước 4: Nhân 3 kết quả

\[ I = \frac{1}{2} \cdot \frac{1}{4} \cdot \frac{4}{3} = \frac{1}{6} \]

\(\boxed{I = \dfrac{1}{6}}\) ✓ Khớp hoàn toàn với đáp án đề bài!

✓ Kết quả: \(\dfrac{1}{6}\)
Kết quả tính toán: \(\dfrac{1}{6}\). Khớp đáp án đề: 1/6 ✓

📊 Hình minh họa

📐 Hình vẽ cho: Tính \(\iiint_\Omega xyz\,dxdydz\), với \(\Omega\) là một phần tám khối cầu \(x^2+y^2+z^2 \le 2,\; x \ge 0,\; y \ge 0,\; z \ge 0\).

💻 Mã nguồn Python (tham khảo)

import sympy as sp
rho, theta, phi = sp.symbols('rho theta phi', real=True, positive=True)
integrand = rho**5 * sp.sin(theta)**3 * sp.cos(theta) * sp.sin(phi) * sp.cos(phi)
I = sp.integrate(integrand, (rho, 0, sp.sqrt(2)), (theta, 0, sp.pi/2), (phi, 0, sp.pi/2))
print("I =", I) # 1/6
