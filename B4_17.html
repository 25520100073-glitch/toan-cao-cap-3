Bài B4.17

Đề bài: Tính \(\iiint_\Omega (x^2+y^2)\,dxdydz\) với \(\Omega\) là khối bán cầu \(x^2+y^2+z^2 \le 1\) nằm phía trên mặt phẳng \(Oxy\).

✎ Lời giải

Bước 1: Thiết lập bài toán trong cả 2 hệ tọa độ (Cầu & Trụ) để kiểm chứng

Miền \(\Omega\) là khối bán cầu đơn vị \(x^2+y^2+z^2 \le 1,\; z \ge 0\).
Cách 1 (Tọa độ cầu): \(0 \le \varphi \le 2\pi,\; 0 \le \theta \le \frac{\pi}{2},\; 0 \le \rho \le 1\), với \(x^2+y^2 = \rho^2\sin^2\theta\) và \(|J| = \rho^2\sin\theta\):

\[ I = \left( \int_0^{2\pi} d\varphi \right) \cdot \left( \int_0^{\pi/2} \sin^3\theta\,d\theta \right) \cdot \left( \int_0^1 \rho^4\,d\rho \right) \]
  • \(\displaystyle \int_0^{2\pi} d\varphi = 2\pi\), và \(\displaystyle \int_0^1 \rho^4\,d\rho = \frac{1}{5}\).
  • \(\displaystyle \int_0^{\pi/2} \sin^3\theta\,d\theta = \int_0^{\pi/2} (1 - \cos^2\theta)\sin\theta\,d\theta = \left[ -\cos\theta + \frac{\cos^3\theta}{3} \right]_0^{\pi/2} = 0 - \left(-1 + \frac{1}{3}\right) = \frac{2}{3}\).
  • \(\implies I = 2\pi \cdot \frac{2}{3} \cdot \frac{1}{5} = \dfrac{4\pi}{15}\).

Cách 2 (Tọa độ trụ): \(0 \le \varphi \le 2\pi,\; 0 \le r \le 1,\; 0 \le z \le \sqrt{1-r^2}\):

\[ I = 2\pi \int_0^1 r^3\sqrt{1-r^2}\,dr = 2\pi \cdot \frac{2}{15} = \frac{4\pi}{15} \]
Lưu ý đính chính slide: Kết quả giải tích chính xác của bài toán này là \(\mathbf{\dfrac{4\pi}{15}}\). Trong slide bài giảng ghi khung đỏ là \(\dfrac{4\pi}{5}\) do lỗi đánh máy (copy nhầm đáp số của Bài B4.7: \(\iiint_{\text{cầu}} (x^2+y^2+z^2)\,dxdydz = \dfrac{4\pi}{5}\)).
🔎 Giải thích chi tiết về chiều cao \(z\):
  • Nếu nhìn theo tọa độ trụ: Từ \(x^2+y^2+z^2 \le 1 \iff r^2 + z^2 \le 1 \iff z^2 \le 1 - r^2\). Vì vật thể nằm "phía trên mặt phẳng \(Oxy\)" nên \(z \ge 0\). Kết hợp lại ta có chiều cao \(0 \le z \le \sqrt{1 - r^2}\).
  • Nếu nhìn theo tọa độ cầu: \(z = \rho\cos\theta \ge 0 \implies \cos\theta \ge 0 \implies \mathbf{0 \le \theta \le \frac{\pi}{2}}\).
✓ Kết quả: \(\dfrac{4\pi}{15}\) (Slide in nhầm \(4\pi/5\) của B4.7)
Kết quả giải tích chuẩn xác: \(\dfrac{4\pi}{15}\) (Đáp số khung đỏ \(4\pi/5\) trong slide bị in nhầm từ bài B4.7) ✓

📊 Hình minh họa

📐 Hình vẽ cho: Tính \(\iiint_\Omega (x^2+y^2)\,dxdydz\) với \(\Omega\) là khối bán cầu \(x^2+y^2+z^2 \le 1\) nằm phía trên mặt phẳng \(Oxy\).

💻 Mã nguồn Python (tham khảo)

import sympy as sp
rho, theta, phi = sp.symbols('rho theta phi', real=True, positive=True)
I = sp.integrate((rho**2 * sp.sin(theta)**2) * rho**2 * sp.sin(theta), (rho, 0, 1), (theta, 0, sp.pi/2), (phi, 0, 2*sp.pi))
print("Chinh xac I =", I) # 4*pi/15
