Bài B4.7

Đề bài: Tính \(\iiint_\Omega (x^2+y^2+z^2)\,dxdydz\), với \(\Omega\) là khối cầu đơn vị.

✎ Lời giải

Bước 1: Đổi biến sang tọa độ cầu

Khối cầu đơn vị là khối cầu tâm \(O(0,0,0)\), bán kính \(R = 1\) có phương trình \(x^2+y^2+z^2 \le 1\).

Áp dụng công thức tọa độ cầu:

  • \(x = \rho\sin\theta\cos\varphi,\; y = \rho\sin\theta\sin\varphi,\; z = \rho\cos\theta\) với \(|J| = \rho^2\sin\theta\).
  • Cận lấy tích phân cho toàn bộ khối cầu: \(0 \le \varphi \le 2\pi,\; 0 \le \theta \le \pi,\; 0 \le \rho \le 1\).
  • Hàm dưới dấu tích phân: \(x^2+y^2+z^2 = \rho^2\).

Bước 2: Tách và tính tích phân 3 lớp

\[ I = \iiint_\Omega (x^2+y^2+z^2)\,dxdydz = \int_0^{2\pi} d\varphi \int_0^\pi \sin\theta\,d\theta \int_0^1 \rho^2 \cdot \rho^2\,d\rho \] \[ = \left( \int_0^{2\pi} d\varphi \right) \cdot \left( \int_0^\pi \sin\theta\,d\theta \right) \cdot \left( \int_0^1 \rho^4\,d\rho \right) \]

Tính từng thừa số:

  • \(\displaystyle \int_0^{2\pi} d\varphi = 2\pi\)
  • \(\displaystyle \int_0^\pi \sin\theta\,d\theta = \Big[ -\cos\theta \Big]_0^\pi = (-\cos\pi) - (-\cos 0) = 1 - (-1) = 2\)
  • \(\displaystyle \int_0^1 \rho^4\,d\rho = \left[ \frac{\rho^5}{5} \right]_0^1 = \frac{1}{5}\)
\[ I = 2\pi \cdot 2 \cdot \frac{1}{5} = \frac{4\pi}{5} \]
🔎 Giải thích chi tiết về chiều cao \(z\) và góc \(\theta\):
  • Vì \(\Omega\) là toàn bộ khối cầu đơn vị \(x^2+y^2+z^2 \le 1\) (lấy cả phần \(z \ge 0\) lẫn phần \(z \le 0\) từ cực Bắc \(z = 1\) xuống cực Nam \(z = -1\)), nên trong tọa độ cầu:
    • Tại cực Bắc \((0,0,1)\): \(z = \rho\cos\theta = 1 \implies \theta = 0\).
    • Tại mặt phẳng xích đạo \(z = 0\): \(\cos\theta = 0 \implies \theta = \frac{\pi}{2}\).
    • Tại cực Nam \((0,0,-1)\): \(z = \rho\cos\theta = -1 \implies \theta = \pi\).
    Do đó góc \(\theta\) quét từ \(0\) đến \(\pi\).

\(\boxed{I = \dfrac{4\pi}{5}}\) ✓ Khớp hoàn toàn với đáp án đề bài!

✓ Kết quả: \(\dfrac{4\pi}{5}\)

📊 Hình minh họa

📐 Hình vẽ cho: Tính \(\iiint_\Omega (x^2+y^2+z^2)\,dxdydz\), với \(\Omega\) là khối cầu đơn vị.

💻 Mã nguồn Python (tham khảo)

import sympy as sp
rho, theta, phi = sp.symbols('rho theta phi', real=True, positive=True)
I = sp.integrate(rho**4 * sp.sin(theta), (rho, 0, 1), (theta, 0, sp.pi), (phi, 0, 2*sp.pi))
print("I =", I) # 4*pi/5
