Bài A4.4

Đề bài: Tính \(\iiint_\Omega (x^2+y^2+z^2)^2\,dxdydz\), với \(\Omega\) là khối bán cầu \(x^2+y^2+z^2 \le R^2,\; z \ge 0,\; (R > 0)\).

✎ Lời giải

Bước 1: Chọn hệ tọa độ cầu

Miền \(\Omega\) là khối bán cầu \(x^2+y^2+z^2 \le R^2,\; z \ge 0\) (\(R > 0\)), và hàm dưới dấu tích phân có dạng \((x^2+y^2+z^2)^2\), nên đổi biến sang tọa độ cầu là tối ưu nhất.

Đặt \(x = \rho\sin\theta\cos\varphi,\; y = \rho\sin\theta\sin\varphi,\; z = \rho\cos\theta\) với \(|J| = \rho^2\sin\theta\):

  • \(0 \le \varphi \le 2\pi\)
  • \(0 \le \theta \le \frac{\pi}{2}\) (vì \(z = \rho\cos\theta \ge 0\))
  • \(0 \le \rho \le R\) (vì \(\rho^2 = x^2+y^2+z^2 \le R^2\))

Bước 2: Thiết lập và tính tích phân

Ta có \((x^2+y^2+z^2)^2 = (\rho^2)^2 = \rho^4\). Nhân thêm \(|J| = \rho^2\sin\theta\) được \(\rho^6\sin\theta\):

\[ I = \left( \int_0^{2\pi} d\varphi \right) \cdot \left( \int_0^{\pi/2} \sin\theta\,d\theta \right) \cdot \left( \int_0^R \rho^6\,d\rho \right) \]
  • \(\displaystyle \int_0^{2\pi} d\varphi = 2\pi\)
  • \(\displaystyle \int_0^{\pi/2} \sin\theta\,d\theta = \Big[ -\cos\theta \Big]_0^{\pi/2} = 0 - (-1) = 1\)
  • \(\displaystyle \int_0^R \rho^6\,d\rho = \left[ \frac{\rho^7}{7} \right]_0^R = \frac{R^7}{7}\)
\[ I = 2\pi \cdot 1 \cdot \frac{R^7}{7} = \frac{2\pi R^7}{7} \]

\(\boxed{I = \dfrac{2\pi R^7}{7}}\) ✓ Khớp hoàn toàn với đáp án bài giảng!

✓ Kết quả: \(\dfrac{2\pi R^7}{7}\)
Kết quả tính toán: \(\dfrac{2\pi R^7}{7}\). Khớp đáp án bài giảng: 2πR⁷/7 ✓

📊 Hình minh họa

📐 Hình vẽ cho: Tính \(\iiint_\Omega (x^2+y^2+z^2)^2\,dxdydz\), với \(\Omega\) là khối bán cầu \(x^2+y^2+z^2 \le R^2,\; z \ge 0,\; (R > 0)\).

💻 Mã nguồn Python (tham khảo)

import sympy as sp
rho, theta, phi = sp.symbols('rho theta phi', real=True, positive=True)
R = sp.Symbol('R', positive=True)
I = sp.integrate(rho**4 * rho**2 * sp.sin(theta), (rho, 0, R), (theta, 0, sp.pi/2), (phi, 0, 2*sp.pi))
print("I =", sp.simplify(I)) # 2*pi*R**7/7
